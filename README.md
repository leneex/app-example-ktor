# Ktor

Пример приложения [Ktor](https://ktor.io/), которое можно развернуть без настройки.

## Параметры деплоя

| Поле | Значение |
| --- | --- |
| Сборка | Railpack |
| Путь до директории проекта | `/` |
| Команда установки зависимостей | оставьте пустым |
| Команда сборки | оставьте пустым |
| Команда запуска | `java -jar build/libs/app.jar` |
| Порт приложения | `4000` |
| Путь проверки состояния | `/health` |

Railpack видит Gradle, ставит JDK 21 и собирает проект; плагин Ktor кладёт исполняемый jar со
всеми зависимостями в `build/libs/app.jar`. Команду запуска указываем явно: сам Railpack ищет jar
только в подпроектах, а у этого проекта он в корне. Приложение слушает порт из переменной окружения
`PORT` — её передаёт платформа, — а без неё `4000`.

## <a name="dev"></a>Локальный запуск проекта

```bash
# запуск в режиме разработки
./gradlew run

# сборка для продакшн и запуск
./gradlew buildFatJar
java -jar build/libs/app.jar
```

Нужен JDK 17 или новее, чтобы запустить Gradle; JDK 21 для сборки Gradle скачает сам, если его нет.
